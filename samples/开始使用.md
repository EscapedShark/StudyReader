# 把资料放进书架

这里保存你想反复阅读的题解、知识点和笔记。普通 Markdown 文件就可以开始。

## 导入一篇文章

点击工具栏的 **＋**，选择“导入 Markdown 文件”。你的原文件会保留，书架保存一份副本。

如果资料里带有图片，选择“导入资料文件夹”，把 MD 和图片一起导入，相对路径就能继续使用。

## 按自己的节奏阅读

- 用搜索栏寻找标题或正文中的词句。
- 点击星标收藏文章，在“收藏”里快速找到。
- 打开文章目录，跳到你想看的章节。
- 在阅读设置里调整字号和外观，或折叠解答。
- 点击数学公式，可以查看并复制 LaTeX 原文。

你离开文章的位置会自动保存，下次可以继续阅读。

## 用熟悉的 Markdown

```markdown
# 条件概率

## 题目
在这里写下问题。

## 思路
先说明为什么选择这种方法。

## 解答
写出推导与结论。
```

行内公式可以写成 `$P(A)$`，块级公式使用 `$$`。
